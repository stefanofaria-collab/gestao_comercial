# Atualização 3.28.0

## Padronização dos filtros

- Mês e ano passaram para os filtros globais nas páginas que trabalham com período.
- Adicionada opção **Ano completo**.
- O seletor de mês permite selecionar um intervalo com **Shift**.
- Intervalos com vários meses são calculados como um único período contínuo.
- Plano e duração passaram para os filtros globais nas páginas que possuem essas informações.
- Os filtros globais também entram nas chaves de cache para impedir mistura entre recortes diferentes.
- Os filtros locais antigos de mês/ano foram ocultados.
- Pagamentos ganhou agregação própria para intervalos com vários meses.
- Mantida a responsividade do menu e da barra global de filtros.
