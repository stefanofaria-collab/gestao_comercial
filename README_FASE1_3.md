FASE 1.3 — ajustes pontuais do faturamento

Itens aplicados nesta entrega:
1. Gráfico de composição com rótulos maiores e ícone de ajuda.
2. Cards finais trocados para "Notas emitidas" e "Ticket médio".
3. Lista "Onde ganhamos e perdemos faturamento" clicável, com modal de variações:
   - mês anterior;
   - acumulado do ano x anos anteriores;
   - mês atual x mesmo mês de anos anteriores.
4. Seletor de comparação: "mês completo" ou "mesmo período atual".
5. Painel "Por empresa" incluindo CertClick e Serviços prestados.
6. "Detalhamento por plano" convertido para ranking visual clicável.
7. Modal do plano com:
   - detalhe por duração;
   - evolução dos últimos 12 meses;
   - mesmos comparativos adicionais.
8. Backend ampliado com endpoints:
   - /api/faturamento/componente
   - /api/faturamento/plano-detalhe

Observação:
- após substituir os arquivos, reinicie backend e frontend.
