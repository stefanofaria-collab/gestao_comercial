# Atualização 3.18.2

## Ajustes

- **Ativos e Atrasados:** texto de regra alterado para usar linguagem de negócio. A interface usa **atraso real** e não exibe nomes técnicos de colunas do banco.
- **Faturamento:** tooltips financeiros dos gráficos de linha passam a usar sempre o padrão brasileiro, por exemplo `R$ 1.111.111,11`.
- **Vencimentos Futuros:** cada dia do calendário agora é clicável e abre a relação completa de clientes daquele dia com os mesmos filtros e opções de exportação da tela principal.
- **Vencimentos Futuros:** seleção de intervalo com `Shift + clique`. O primeiro Shift+clique marca a data inicial e o segundo marca a data final. Todo o intervalo fica destacado.
- **Vencimentos Futuros:** ao concluir um intervalo, é exibido um resumo com valor total de vencimentos e total de clientes. O usuário pode abrir a lista completa do intervalo.
- **Exportação:** rótulos técnicos foram substituídos por nomes mais fáceis de entender, sem remover os dados exportados.
